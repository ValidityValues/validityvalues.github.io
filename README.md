# J5 Prime Lag OS — Lagsung Labs

**Live demo:** [Open J5 Prime Lag OS](https://rawcdn.githack.com/ValidityValues/j5primelagweb/ad4cdccf74a50e7d2eabc8d23b23cb836caf86fd/index.html)

**Development preview (tracks `main`):** [raw.githack.com](https://raw.githack.com/ValidityValues/j5primelagweb/main/index.html)

Абсурдный интерактивный сайт про виртуальный Samsung J5 Prime, который воспринимает каждое нажатие как философский вопрос.

## Что внутри

- Интерактивный телефон и 12 приложений: телефон, сообщения, камера, галерея, браузер, YouTube-пародия, музыка, файлы, настройки, магазин, терминал и доска объявлений.
- Нажатие на приложение запускает обязательный таймер на **20 секунд**, после чего показывается приложение на миг и затем реалистично оформленный **Linux-style Kernel Panic на TTY1**.
- Перезагрузка симуляции, стресс-кнопки, телеметрия, журнал событий и панель управления.
- Финальная абсурдная доска объявлений и сюрприз **«ДА БОЖЕЕЕЕ»**.
- Адаптивная вёрстка; никаких npm, внешних библиотек или сборки для самого сайта.

## Локальный запуск

Открой `index.html` в современном браузере.

## Постоянная публикация через GitHub Pages

Для адреса `https://validityvalues.github.io/j5primelagweb/` один раз открой **Settings → Pages** и выбери **Source: GitHub Actions**. Затем workflow `.github/workflows/pages.yml` опубликует сайт автоматически при push в `main`. Включить эту настройку через доступную GitHub-интеграцию не получилось из-за ограничения её прав, поэтому демо выше уже доступно отдельно через публичный CDN-прокси.
