# J5 Prime Lag Edition — Lagsung

Абсурдный интерактивный сайт про виртуальный Samsung J5 Prime, который воспринимает каждое нажатие как философский вопрос.

## Что внутри

- Виртуальный телефон с рабочим экраном блокировки и приложениями: камера, галерея, браузер, YouTube-пародия, музыка, файлы, настройки, заметки, магазин, телефон и доска объявлений.
- Намеренные задержки, фальшивые обновления, системные уведомления и живой журнал событий. Браузер намеренно не блокируется по-настоящему.
- Сюжетная кнопка **«Запустить эпопею»** — загрузка до 99%, браузерный кризис, доска объявлений и финальный сюрприз **«ДА БОЖЕЕЕЕ»**.
- Адаптивная верстка, анимации и эффекты звука без внешних библиотек.

## Локальный запуск

Открой `index.html` в современном браузере. Сборка, npm и сторонние зависимости не нужны.

## Публикация через GitHub Pages

1. Открой **Settings → Pages** в этом репозитории.
2. В блоке **Build and deployment** выбери **Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` автоматически опубликует сайт при push в `main` и при ручном запуске.

После успешного деплоя адрес будет `https://validityvalues.github.io/j5primelagweb/`.
